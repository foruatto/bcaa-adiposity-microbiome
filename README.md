# BCAA, adiposity, cardiometabolic outcomes, and gut microbiome

This repository contains the R code used for the analyses reported in this study.

## Code

- `UKB_analysis.R`: Analysis code for the UK Biobank analyses.
- `microbiome_analysis.R`: Analysis code for the curatedMetagenomicData analyses.

## Data availability

Individual-level UK Biobank data are not included in this repository because redistribution is restricted under the UK Biobank data access policy. Eligible researchers may apply for access through UK Biobank.

The metagenomic analyses were based on publicly available datasets accessed through curatedMetagenomicData.
